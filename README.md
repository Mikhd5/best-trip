# BEST TRIP — website concept

Static, responsive landing page prepared for Vercel deployment.

## Preview locally
Open `index.html` in a browser, or run a static server from this directory:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy to Vercel
Import the project folder/repository as a static site. No build command is required; the output directory is the project root.

## Booking flow
The request form validates the required fields and opens WhatsApp with a prefilled message to **+380 96 999 07 99**. The visitor reviews and sends the message in WhatsApp; the website does not claim that the request has been delivered automatically.

## Facts intentionally not invented
No route cities, prices, departure schedule, seat count, exact vehicle count, business address, Telegram handle, or confirmed service guarantees are shown. The visible country destinations and two phone numbers come from the supplied materials. The fleet section uses the supplied photos, with a generated hero vehicle photo.

## Before public launch
Confirm the displayed brand name, WhatsApp availability for the primary number, preferred brand colors/logo, departure cities, route cities, schedules, fares, luggage rules, and official Telegram handle (if one should be linked).
